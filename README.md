# 🐍 Snake Species Classification using YOLO

An AI-based Snake Species Classification project built using Python and YOLO.

This project detects and classifies different snake species from images using a trained YOLO deep learning model.

## 🚀 Features

- Snake species detection and classification
- YOLO-based deep learning model
- Image-based prediction
- Fast object detection
- Multiple snake species classification
- Prediction result visualization

## 🧠 Technologies Used

- Python
- YOLO / Ultralytics
- OpenCV
- PyTorch
- NumPy

## 🐍 Supported Snake Species

1. Bamboo Pit Viper
2. Banded Krait
3. Black-headed Snake
4. Common Bronzeback Snake
5. Common Sand Boa
6. Common Vine Snake
7. Indian Cobra
8. Indian Rock Python
9. Ornate Flying Snake
10. Russell's Viper

## 📂 Project Files

- `app.py` – Main application
- `train.py` – Model training
- `predict.py` – Prediction
- `data.yaml` – Dataset configuration
- `best.pt` – Trained YOLO model
- `final_result.jpg` – Result image
- `snake_result.jpg` – Prediction result
